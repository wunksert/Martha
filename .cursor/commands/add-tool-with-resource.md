# Purpose
Create a MCP tool with a resource react layout

# Instructions
1. Create a new tool in @/src/tools.ts. Create your handler in @/src/handlers
2. Create a new resource in @src/resources.ts
3. Create a base html file for the resource in @/ui
4. Create a react file in @/ui for the resource UI
5. Create a hmr-template for realtime development with hmr in /ui/hmr-templates

# Rules
1. Make sure state management follows rules/managing-state.mdc

# Conventions
1. Create new hooks as necessar to access window.openai Apps SDK globals. Create them in @/ui/hooks.ts
