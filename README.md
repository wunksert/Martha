# Express.js TypeScript Server

A simple Express.js server built with TypeScript.

## Setup

Install dependencies:
```bash
npm install
```

## Development

Run in development mode with hot reload:
```bash
npm run dev
```

## Build

Build the project:
```bash
npm run build
```

## Production

Start the production server:
```bash
npm start
```

## Type Checking

Run type checking without building:
```bash
npm run type-check
```
